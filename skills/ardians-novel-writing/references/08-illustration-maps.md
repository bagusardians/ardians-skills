# Phase 8: Illustration, Images, and Maps

Produce the visual and typeset package. This phase composes `theme-factory`,
`frontend-design`, `canvas-extension-api`, and `pdflatex`.

## Steps

1. **Set the visual theme.** Use `theme-factory` to choose or generate a palette and
   typography that fit the book's tone.
2. **Cover art.** Use `frontend-design` to compose the cover: title, author, imagery, and
   layout, at print and ebook dimensions.
3. **Interior illustrations.** Produce interior art or section ornaments to the same
   theme. State the intended placement.
4. **Maps.** Produce setting maps. Use `canvas-extension-api` when an interactive or
   appendix map is wanted; otherwise render a static map plate.
5. **Typeset.** Use `pdflatex` to typeset the manuscript with the cover, illustrations,
   and map plates, and produce a final PDF.
6. **Rights check.** Use only original or properly licensed assets. Do not reproduce
   copyrighted characters or artwork.

## Deliverable

Cover art, interior illustrations, map plates, and a typeset PDF.

## Gate

Present the visual package and the PDF, then confirm before declaring the book done.

## Checklist

- Theme is consistent across cover, interior, and maps.
- Assets are original or licensed.
- The typeset PDF builds and includes every plate.
- File names and dimensions suit print and ebook.
